primeira pagina usando HTML com bootstrap

O Bootstrap é um framework de desenvolvimento web que facilita a criação de sites e aplicações responsivas, oferecendo uma coleção de componentes, estilos e ferramentas prontos para uso, como botões, menus, formulários, tabelas, cards e sistemas de grid.

Ele permite que desenvolvedores criem interfaces modernas e adaptáveis a diferentes tamanhos de tela de maneira mais rápida, reduzindo a necessidade de escrever CSS e JavaScript do zero.
